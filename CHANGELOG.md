# Changelog

All notable changes to this project are documented in this file. The format is
based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added

- Licensed under the Apache License 2.0 with a NOTICE file (credits),
  THIRD_PARTY_NOTICES.md (generated by `make notices`) and CONTRIBUTING.md.
- Notice in README, `paygate about` and the app that paygate is an unofficial
  tool used on one's own responsibility.
- Colour themes: Settings → Colour theme (or the command palette) switches
  between Blue (default) and Blurple at once. The choice is saved as
  `theme` in config.toml and also colours the output of the commands.
- Factory reset: `paygate reset` and Settings → Delete all data (also in the
  command palette) delete all profiles with their API keys in the keychain,
  the settings, the payment history and the request log. Payments at Paygate
  are not affected.

### Changed

- New app frame: version and profile sit in the top border, menu, content and
  footer are joined with proper junctions, a small PAYGATE · CLI stamp closes
  the frame. Production no longer turns the whole frame red; the PROD badge
  stays red.
- QR codes are drawn with fixed black and white colours and a quiet zone, so
  they scan in every colour scheme and with extra line spacing. They also
  scan in terminals that draw block characters from the font, such as
  Terminal.app.
- The QR code fits smaller windows: the URL moved next to it and the quiet
  zone is one module (a real Paygate link fits 120 × 30). If it still does
  not fit, `z` shows the code full screen while the app keeps waiting.
- Direct card payments offer only the test cards without 3-D Secure, one
  line per card. The 3DS cards need a browser and work on the payment page.
- Operations carry their Paygate API names everywhere: Capture, Refund and
  Reversal (no more "release" or "erstatten"). `paygate cancel` is now
  `paygate reverse`; `cancel` keeps working.
- The Test cards screen is gone. While a payment page waits, the test
  system shows the cards to type in (Visa, 3DS challenge with OTP); the
  command palette copies any test card number ("3ds", "amex" …), and
  `paygate testcards` still lists them all.
- Selected rows are a continuous band with bright text and an accent bar in
  every list, the menu and the command palette, and stay readable in
  terminals with 256 colours such as Terminal.app. A list without the
  keyboard focus only keeps the bar, so it is clear where keys go.

### Fixed

- Direct card payments with a test card without 3DS got stuck on production
  with `70000000 AUTHENTICATION_REQUIRED`: Paygate starts 3-D Secure for
  every card there. These test cards now ask Paygate to skip it
  (`threeDsPolicy.skip`). Own cards can skip it too, in the app and in
  `paygate pay`.
- The result of a payment had no way back: `esc` and `shift+tab` now return
  to the review, and from there to the form.
- Going back from the review left the content empty until the next key.
- Typing in the command palette could duplicate commands and hide others.
- The checkout URL on the wait screen could neither be selected nor clicked,
  because the app owns the mouse. A click on it now opens it in the
  browser, and the URL is headed by "c copies · click opens".
- The time a customer spent on the payment page kept counting up on the
  result; it now stops with the final status and reads "Duration · 1m5s on
  the payment page".
- The column headers of the payments list are aligned with their columns.
- Forms no longer hide their last options when a description wraps, and the
  payment form uses the width of the window from the start.

## [0.2.0]

### Added

- Full-screen app: `paygate` without a command opens it. Sidebar with Home,
  Test cards, Profiles (add, switch, verify, delete) and Settings; footer key
  hints, `?` help, mouse support and tabs in narrow windows. New payment,
  Payments and Inspector follow in the next steps.
- New payment in the app: form, review with request JSON and copy as curl,
  send, result. Hosted pages and 3-D Secure show a QR code and live status;
  results can be sent again, released (manual capture) or refunded.
- Simulation: `--simulate ok|decline|<code>` and a switch in the app send the
  order description `Test:0000` / `Test:0305`, which Paygate treats as a test
  transaction even on production. Production profiles default to simulation,
  0.01 and manual capture.
- Local payment history (`history.jsonl`, IDs, amounts and states only) for
  payments, lookups and follow-up operations.
- Payments in the app: history with filter, lookup by payId or transId,
  details with captured/refunded amounts, timeline, request JSON, and capture,
  refund (full or partial), release and refresh. Home shows today's numbers
  and the latest payments. `paygate history` lists the same on the command
  line (`--all`, `--limit`, `-o json`).
- Inspector in the app: the last 200 requests to Paygate from the app and the
  command line (`requests.jsonl`) with request/response headers and JSON,
  status, timing and correlation ID; copy body or curl, clear the log.
  Credentials are never logged, card numbers and CVC are masked.
- Command palette (`ctrl+k` or `ctrl+p`): fuzzy search over every action in
  English and German: go to screens, look up or open the last payment, copy
  the last pay ID, switch profile, switch language, clear the request log.
- ASCII art: start screen with the large PAYGATE logo (credentials are checked
  meanwhile; can be switched off in Settings or with PAYGATE_NO_SPLASH), small
  logo in the sidebar and results printed as a receipt (d shows the details).
- English and German interface, chosen automatically or in Settings.
- `init` checks test and production, Nexi and Computop, Basic and OAuth2 in
  parallel when the credentials are rejected.

### Fixed

- Direct card payments send `browserInfo.ipAddress`, which Paygate requires
  ("Browser Info Ip Address must not be empty"). It defaults to this computer's
  address and can be set per profile (`customer-ip`, Settings) or with `--ip`.
- Spaces, line breaks and invisible characters around pasted merchant IDs and
  API keys no longer cause 401 errors.

## [0.1.0]

First MVP.

### Added

- `paygate init` and `paygate profile` (list, use, show, set, delete) with API
  keys in the system keychain and credential verification before saving.
- `paygate pay` with an interactive wizard and flags for three flows: hosted
  payment page (`--hosted`), hosted single method (`--method`) and direct card
  payments (`--card`, `--card-number`).
- Live waiting for hosted checkouts and 3-D Secure challenges, with QR code,
  open-in-browser and copy shortcuts.
- `paygate get`, `paygate capture`, `paygate refund` and `paygate cancel` with
  confirmation and automatic amounts.
- `paygate testcards` with aliases for the official test cards.
- Global `-o json`, `--curl`, `-v`/`-vv` with redacted credentials, `--yes` and
  `--no-color`.
- Nexi and Computop hosts, test and production, Basic Auth and OAuth2.
- Local mock Paygate (`tools/mockpaygate`) for demos and tests.
